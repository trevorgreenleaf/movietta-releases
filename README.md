# Movietta

Movietta turns a folder of everyday clips into an edited video, privately, on your Mac. Your footage never leaves it.

**Download:** the latest version is under [Releases](https://github.com/trevorgreenleaf/movietta-releases/releases/latest).

Requires a Mac with Apple Silicon (M1 or later) running macOS 12 or newer.

## Open-source parts

Movietta includes open-source software. The full list of licenses is inside the app (Settings › App › Open-source licenses).
Its ffmpeg and ffprobe are GPL. Each release attaches the exact ffmpeg and x264 source they were built from.
